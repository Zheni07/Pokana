# Покана за абитуриентски бал — Жени Живкова

Елегантен luxury invitation website с watercolor естетика, златисти рамки и флорални декорации.

## Стартиране

Отвори `index.html` в браузър или стартирай локален сървър:

```bash
npx serve .
```

## Редактиране на съдържанието

Всички текстове, дати, линкове и снимки се променят в **`config.js`**:

| Секция | Какво редактираш |
|--------|------------------|
| `hero` | Текст на поканата: ПОКАНА, име, дата (30 май), час, локация |
| `event` | Дата, час, локация, адрес |
| `map` | Координати, адрес за Google Maps |
| `countdown.targetDate` | ISO дата/час за таймера (`2026-06-15T19:00:00`) |
| `gallery.images` | Масив от снимки |
| `footer` | Послание, социални мрежи |

## Снимки и музика

1. Замени `assets/photo.svg` с твоя снимка → `assets/photo.jpg` и обнови `hero.photo` в config.
2. Добави снимки в галерията → `assets/gallery-1.jpg` и т.н.
3. Сложи MP3 файл в `assets/music.mp3` за фонова музика (бутон горе вдясно).

## Навигация от текуща локация

- **Навигирай от моята локация** — използва GPS и отваря Google Maps с маршрут от теб до къщата за гости.
- Работи най-добре през **HTTPS** или локален сървър (`npx serve .`), не с `file://`.
- При отказан GPS — виж само дестинацията или Waze.

Координатите се задават в `map.latitude` / `map.longitude`.

Картата използва embed без API ключ. При нужда смени `map.placeQuery` с точния адрес.
